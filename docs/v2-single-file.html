Operating notes

  1. Press Power. Sound starts then.
  2. Drag the dial sideways. It has weight, and it plays as it turns.
  3. Listen for the whistle and watch the signal lamps. Stations keep to the marked metre bands, mostly.
  4. Whatever is spoken prints here, so the set works with the sound off.
  5. Ten stations are on the air tonight. One would rather not be found.
